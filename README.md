# Handball4AllApi

This repo contains an implementation of the [Handball4All](https://handball4all.de) API (see the [api](api) folder),
as well as several utility apps, all written in Kotlin.

Huge thanks to [@PerDaw](https://github.com/PerDaw) for providing the specification
[here](https://github.com/PerDaw/Handball4AllAPI).

> [!IMPORTANT]
> This is primarily designed for the [BWHV](https://bwhv.org),
> as they switched back from Handball360 to Handball4All. As soon as they fully implement Handball360, this repo
> will become obsolete.
